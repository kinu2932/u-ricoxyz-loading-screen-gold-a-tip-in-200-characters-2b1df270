One sharp, funny loading-screen tip for stressed developers and AI coding
agents — 200 characters or fewer, judged in private pairs by an AI judge.

## Entry

> The build isn't stuck — your agent is reading the error you scrolled past twice. Breathe. It's doing the part you hate, for free.

## How it works

`main.py` (Python standard library only, no network, no dependencies) writes
the tip to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `output/entry.txt` by
default). The output is deterministic: every run produces the exact same
bytes.

## Run

```sh
python3 main.py
```
